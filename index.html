🔒 プライバシーポリシー

1. 取得する情報

当サービスでは、Googleログインによる基本情報（UID、メールアドレス等）、およびユーザーが任意で入力したプロフィール情報（氏名、住所、電話番号等）を取得・保存します。

取得した個人情報は、ユーザー間での取引を成立させるための情報共有（取引相手への開示）、サービスの提供・運営、およびお問い合わせ対応のためにのみ利用します。

3. 第三者への開示・提供

当サービスは、ユーザー間の取引において成立後に取引相手へ情報を開示する場合、または法令に基づく場合を除き、事前の同意なく個人情報を第三者に提供・開示することはありません。

4. 情報の保護と管理

ユーザーの個人情報はFirebaseの強固なセキュリティルールにより保護され、取引の当事者およびシステム管理者以外がアクセスすることはできません。ユーザーがアカウントの削除を希望する場合、またはデータ削除の要請があった場合、速やかにデータを削除します。

5. 免責事項

ユーザー自身の操作により取引ルームなどで過剰に開示された情報に起因するトラブルについて、運営は一切の責任を負いません。外部要因（ハッキング等）による不可抗力な情報漏洩についても同様とします。ご自身の判断において安全に利用してください。

・1人あたりメンバー1つまで：同じ企画につき、お一人様1メンバー（1枠）までのお申し込みとなります。

・メンバー枠は完全先着順です：人気メンバーの枠は申し込み順に埋まり、上限に達したメンバーから受付終了となります。

【Auto-GOの仕組み】

  1. 1.
    仮予約（エントリー）
    • 希望メンバーを1人選んで仮予約します（参加には配送先住所とXアカウントの登録が必要です）。
    • 募集締切までに最低成立人数（通常20人）に達すると企画が成立し、本確定となります。未達の場合は自動キャンセルされ、購入は不要です。
  2. 2.
    企画成立後、購入用URLが届くので各自でCDを購入・報告
    • 企画成立後、プッシュ通知・アプリ内通知（およびX等）にて対象ショップの購入用URLが届きます。
    • 指定期限までにそのURLから各自でCDを1枚購入し、購入完了スクリーンショットを登録してください。
  3. 3.
    到着報告・開封結果の登録（※自引きの場合も必須）
    • 手元にCDが届いたら到着報告を行い、封入されていたランダムトレカのメンバー（開封結果）を必ず登録してください。
    • ※希望メンバーを「自引き」した場合でも、全体の集計・自動割り当て確定のために開封結果の登録が必須です（登録完了後、自引きの方は発送不要でそのまま終了となります）。
  4. 4.
    最短ルート自動割り当て
    • 自引き以外のメンバー同士をシステムが最短の循環ルートで自動割り当てし、1回の発送で希望トレカが届くように配送先を指定します。
    • ※組み合わせの都合上割り当て対象外となった場合は、手元のトレカをそのままお持ち帰りとなります（発送不要）。
  5. 5.
    発送・受取完了
    • マッチング確定から72時間以内に、割り当てられた相手へトレカを発送し、発送伝票（または投函・追跡証明）の写真を登録します。
    • ※あなたの発送伝票を登録するまで、自分宛てに送ってくれる相手の情報はロックされます。
    • 双方の受取完了をもって取引終了です。

※個人間のチャットや交渉は一切不要です。システムが自動で割り当てた送り先住所へそのまま発送するだけで希望メンバーのトレカが届きます

開封結果の未登録・期限超過は進行の妨げとなるためペナルティ対象となります

【必ず守るルール】

  • 事前登録・通知設定の必須化：エントリー前に「氏名・郵便番号・住所」「XアカウントID」の登録、および「プッシュ通知のオン」が必要です。
  • 成立後のキャンセル不可：最低人数に達して企画が成立した後は、自己都合での購入キャンセルはできません。
  • 72時間以内の発送義務：マッチング確定後、72時間以内に発送および伝票写真の登録を行ってください。期限超過は永久停止の対象です。
  • 伝票画像の使い回し禁止：発送証明画像は重複検知されます。
  • 発送方法の統一（追跡必須）：普通郵便は禁止。クリックポスト等の追跡ありで発送してください。
